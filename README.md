# Контрольная работа №2 — Bootstrap Shop

**Тема:** CSS-фреймворки: разработка интерфейса на Bootstrap.

Учебный многостраничный интернет-магазин, созданный с использованием Bootstrap 5.3.8. Проект демонстрирует адаптивную сетку, готовые компоненты и utility-классы Bootstrap.

## Практическая работа №9

Реализована главная страница на Bootstrap-сетке:
- подключение Bootstrap CSS и JS Bundle через CDN;
- собственный файл `css/custom.css`;
- адаптивная навигация;
- hero-блок на сетке `container / row / col-*`;
- блок преимуществ;
- карточки популярных товаров;
- адаптивные колонки `col-12 col-md-6 col-lg-4`;
- отступы `g-*`, utility-классы и подвал страницы.

## Практическая работа №10

Проект расширен компонентами Bootstrap:
- страницы каталога, товара и формы заявки;
- navbar на всех страницах;
- карточки `card`, метки `badge`, сообщения `alert`;
- модальное окно `modal` с демонстрационной формой;
- форма с `form-control`, `form-select`, `input-group`, `form-check`;
- таблица характеристик и хлебные крошки;
- раскрывающийся список `accordion`;
- JavaScript для демонстрационной проверки форм.

## Запуск

Откройте `index.html` в браузере. Для удобной локальной разработки можно использовать расширение Live Server в Visual Studio Code. Bootstrap загружается через CDN, поэтому для его стилей и интерактивных компонентов требуется подключение к интернету.

## Важно

Это учебный frontend-проект. Форма демонстрирует HTML-валидацию и интерфейсное сообщение; backend и реальная отправка заявок не реализованы, поскольку этого не требуют практические занятия №9–10.
